# 发票抽奖记账工具 · 部署给朋友使用指南

你的工具是一个**单文件网页**，数据存在每个人的浏览器本地（localStorage），所以天然就是「各自独立记账」——朋友打开同一个网址，各记各的，互不影响。下面按难度从低到高给你三种托管方法。

---

## 方法一：Netlify Drop（最简单，强烈推荐）

不需要注册域名、不需要命令行，拖文件就行。

1. 打开 https://app.netlify.com/drop （首次用会让你注册，用邮箱或 GitHub 登录即可，免费）
2. 把 `发票抽奖记账.html` 直接**拖进网页中间的虚线框**
3. 几秒钟后它会给你一个网址，长这样：`https://随机名字.netlify.app`
4. 点进网址确认能正常打开，然后把这个网址发给朋友就行

想换好看的名字：登录后在 Site settings → Change site name 里改，比如改成 `fapiaodraw.netlify.app`。

> 国内访问 Netlify 有时较慢。如果朋友觉得卡，用下面方法二或方法三。

---

## 方法二：Vercel（也简单，国内稍快）

1. 打开 https://vercel.com ，用 GitHub 或邮箱注册
2. 进入 Dashboard → Add New → Project
3. 选择 **Deploy without Git**（不需要代码仓库）
4. 把 `发票抽奖记账.html` 拖进去
5. 部署完会得到 `https://xxx.vercel.app` 网址，发给你朋友即可

---

## 方法三：GitHub Pages（免费且稳定，适合长期）

需要注册 GitHub 账号（免费），稍微学一下 Git 或直接用网页操作：

1. 注册 https://github.com
2. 新建一个仓库（Repository），名字随意，如 `invoice-lottery`
3. 网页端进入仓库 → Add file → Upload files，把 `发票抽奖记账.html` 上传
4. 仓库 Settings → Pages → Source 选 `main` 分支 → Save
5. 等 1-2 分钟，得到 `https://你的用户名.github.io/invoice-lottery/`
6. 打开那个网址确认可用后发给朋友

---

## 方法四：国内访问快的方案（可选）

如果朋友都在国内、访问国外平台慢，可以：

- **Gitee Pages**（码云）：https://gitee.com 类似 GitHub，但国内访问快，不过需要实名认证，免费版偶尔要求手动刷新
- **腾讯云 COS / 阿里云 OSS 静态网站**：有免费额度，但需要配置，稍麻烦
- **Cloudflare Pages**：免费，全球 CDN，国内访问比 Netlify/Vercel 略好，方法同 Netlify（拖文件即可）

## 发给朋友前必看

### 手机端使用
- 网址用微信/浏览器打开就能用，**建议加到手机桌面**：
  - iPhone：Safari 打开 → 分享按钮 → 添加到主屏幕
  - 安卓：Chrome/自带浏览器 → 菜单 → 添加到主屏幕 / 添加到桌面
- 加了桌面图标后打开更像一个「App」，体验更好

### 重要：数据备份
工具的数据存在**每个使用者自己的浏览器**里，这带来两个注意事项：

1. **换手机 / 清缓存会丢数据** —— 一定要提醒朋友：
   - 工具底部有 **「💾 备份数据」** 按钮，点击会下载一个 `.json` 文件
   - 换个手机或重装浏览器前，先备份，再在新设备上用 **「📥 恢复数据」** 导入
2. **各自的数据互相看不到** —— 这正是「各自独立记账」的效果，如果以后想改成「几个人共用一份账」，需要另做带账号和云存储的版本

### 更新工具
以后我帮你改了新版，只需要把新的 `发票抽奖记账.html` 用同样的方式重新部署一遍（Netlify/Vercel 直接覆盖拖入，GitHub 覆盖上传），网址不变，朋友打开就是新版。**朋友的旧数据不受影响**（存在他们浏览器里）。

## 常见问题

**Q：朋友打开是空白或乱码？**
A：用最新版 Chrome、Edge、Safari 打开，别用太老的浏览器。手机端推荐系统自带浏览器或 Chrome。

**Q：换手机后数据怎么带过去？**
A：旧手机上点「💾 备份数据」得到 json 文件 → 把文件发给自己（微信文件传输助手/邮箱）→ 新手机上打开网址 → 点「📥 恢复数据」→ 选择那个 json 文件。

**Q：能多人共用一份数据吗？**
A：现在的版本不行（各存各的）。如果你确实需要共用，告诉我，我可以帮你规划一个带登录和云存储的版本（可以用 Supabase 等免费后端）。

**Q：文件名字是中文的，部署会不会有问题？**
A：一般没问题。如果你部署时遇到麻烦，可以把文件改名成 `index.html` 再部署（更通用），或者告诉我，我直接生成一个 `index.html` 版本给你。
