# 发票抽奖记账工具

按城市记录发票购入、出票、上传、抽奖与中奖情况，支持多账户、剩余发票汇总、待处理提醒、数据备份/恢复、CSV 导入导出。

## 使用

直接访问：https://asapbobovo-ui.github.io/fapiao/

## 数据迁移

如果你在使用旧版本工具（没有「备份/恢复」功能），可以用 **CSV 迁移**：

1. 在旧版本页面点「导出 CSV」，下载 csv 文件
2. 在新版页面底部点「📥 导入 CSV」，选择该文件
3. 数据会自动合并进来（账户、城市、张数、成本、状态、奖金、盈损都会解析）

## 数据安全

- 数据保存在各使用者自己的浏览器本地（localStorage）
- 建议定期点「💾 备份数据」下载 json 备份
- 换设备/清缓存前先备份，再到新设备用「📥 恢复数据」导入
